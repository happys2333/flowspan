## What this proves

- Commit `f6bcaf3` checks out with LF-normalized source on GitHub-hosted Windows,
  macOS, and Ubuntu runners.
- Commits through `c3a5aa2` restore locked packages, pass repository formatting,
  compile with warnings treated as errors, run the committed test suites and
  simulator, and upload test evidence on all three hosted OS images.
- The signed discovery, expiry/deduplication, identity-change, and reconnect
  backoff primitives committed in `adb1811` pass on all three hosted OS images.
- The authenticated ephemeral handshake, bounded direct TCP control channel,
  identity/version binding, hostile frame limits, and handshake timeout committed
  in `e464194` pass on all three hosted OS images.
- The identity-store port, atomic provisioning behavior, deletion/restart
  lifecycle, concurrent first-launch convergence, and explicit degraded-store
  classification committed in `e11e7e8` pass on all three hosted OS images.
- The bounded/versioned identity payload codec, canonical round trip, hostile
  input rejection, and PKCS#8 validation committed in `71d25c7` pass on all
  three hosted OS images.
- The Windows atomic-file contract passes on all three images. The Windows job
  also executes a disposable CurrentUser DPAPI create/reload/delete smoke; the
  macOS and Ubuntu jobs verify that the production protector rejects use outside
  Windows rather than degrading.
- The macOS Keychain contracts pass on all images. The macOS job also executes
  disposable Security.framework create/reload/delete and concurrent `SecItemAdd`
  smoke tests; Windows and Ubuntu verify explicit platform rejection.
- The committed history passed the configured secret scan, and the C# source
  passed the configured CodeQL workflow.

## What this does not prove

- The uncommitted Linux Secret Service adapter; it needs its own CI and desktop
  Secret Service evidence.
- DPAPI behavior in locked profiles, Windows services, roaming profiles, signed
  packages, or physical-machine installation contexts.
- Keychain ACL/prompt behavior in signed/notarized packages, locked login
  Keychains, or migrated user profiles.
- Physical-device LAN discovery, multi-interface/VPN behavior, sleep/wake, or
  IPv4/IPv6 interoperability.
- Native permission, capture, protected-surface, remote-input, accessibility,
  packaging, signing, install, update, or long-duration behavior on real Windows,
  macOS, or Linux machines.
- Absence of vulnerabilities or secrets beyond the configured scanners' scope.

Those claims remain open in `docs/release/v1-release-criteria.md`.
