  identity/version binding, hostile frame limits, and handshake timeout committed
  in `e464194` pass on all three hosted OS images.
- The identity-store port, atomic provisioning behavior, deletion/restart
  lifecycle, concurrent first-launch convergence, and explicit degraded-store
  classification committed in `e11e7e8` pass on all three hosted OS images.
- The bounded/versioned identity payload codec, canonical round trip, hostile
  input rejection, and PKCS#8 validation committed in `71d25c7` pass on all
  three hosted OS images.
- The Windows atomic-file contract passes on all three images. The Windows job
  also executes a disposable CurrentUser DPAPI create/reload/delete smoke; the
  macOS and Ubuntu jobs verify that the production protector rejects use outside
  Windows rather than degrading.
- The macOS Keychain contracts pass on all images. The macOS job also executes
  disposable Security.framework create/reload/delete and concurrent `SecItemAdd`
  smoke tests; Windows and Ubuntu verify explicit platform rejection.
- The Linux `secret-tool` contracts pass on all images. Ubuntu additionally
  executes missing-tool recovery, bounded-output, cancellation, and process-tree
  termination tests; Windows and macOS verify explicit platform rejection.
- Trust revocation, capability-downgrade session selection, concurrent admission
  rejection, and stop-failure fan-out pass on all three hosted OS images.
- The canonical bounded trust codec, golden fixture, persistent authority
  restart/failure/concurrency contracts, durable revoke ordering, and local
  shutdown draining pass on all three hosted OS images through a protected-store
  contract fake.
- The macOS job additionally persists trust through a disposable
  `WhenUnlockedThisDeviceOnly` Keychain item and exercises atomic
  `SecItemUpdate`, create-race recovery, restart, capability update, and
  revocation. This is hosted user-profile evidence, not signed-package or
  locked-Keychain evidence.
- The Windows job persists trust through CurrentUser DPAPI with a separate trust
  context, fsynced same-directory atomic replacement, restart, capability
  update, and revocation. This is hosted user-profile evidence, not a signed
  package, service account, locked profile, or physical-machine result.

  passed the configured CodeQL workflow.
